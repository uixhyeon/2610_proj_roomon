# ROOMON — 나의 몰입을 예약하다

`2610_proj_roomon` · 2026년 10월 포트폴리오 프로젝트

무인 연습실·회의실 예약 서비스의 작동하는 포트폴리오 MVP입니다.

## 실행

Node.js 22.13 이상(권장 25)이 필요합니다. 별도 패키지 설치는 없습니다.

1. 압축을 해제합니다.
2. `start.command`를 실행하거나 이 폴더에서 `node scripts/preview.mjs`를 실행합니다.
3. 브라우저에서 http://localhost:4173 을 엽니다.

macOS가 실행 파일을 차단하면 터미널에서 위 Node 명령을 사용하세요.
예약은 로컬 `.local.sqlite` 파일에 저장됩니다. 브라우저 쿠키가 내 예약을 연결하므로 같은 브라우저를 사용하세요. 사진·폰트·QR 라이브러리는 인터넷 연결이 필요합니다.

## 3분 시연 순서

1. 공간을 선택하고 날짜·시간·인원·정책 동의를 입력한 뒤 테스트 결제합니다.
2. 내 예약에서 출입 QR을 발급하고 검증 버튼을 두 번 눌러 1회 사용 제한을 확인합니다.
3. 관리자 화면에서 지연 시간 25분을 입력하고 후속 예약·퇴실 확인에 체크합니다.
4. 내 예약에서 추가 요금 결제를 시연합니다.
5. 예약 취소 시 환불액을 확인하고 같은 시간에 다시 예약해 봅니다.
6. 새 예약에서 결제 실패 시연에 체크하면 예약이 생성되지 않습니다.

## 구현된 기능

- 서버 저장, 시간 중복 방지 및 트랜잭션 원자성
- 룸별 정원 제한, 지난 시간 예약 방지
- 테스트 결제 성공·실패, 취소 및 남은 시간에 따른 환불 계산
- 10분·1회용 QR 토큰, 재발급 시 이전 토큰 무효화
- 관리자 예약 현황, 지연 요금 청구, 고객 측 테스트 수납
- 고객/관리자 화면, 모바일 대응 CSS, 이용 정책 안내

## 범위와 제한

실제 PG 결제·환불, 계정 로그인, 문자·전화, CCTV·출입문, 정기권·반복 예약·마일리지·크레딧·탈퇴는 구현 범위에 포함되지 않습니다.
관리자는 소유자 전용 시연 역할입니다. 공개 서비스로 전환하기 전에 인증·권한과 운영 정책을 구현해야 합니다. 지연 요금 시연은 같은 브라우저에서 만든 예약에 적용됩니다.
QR 공유 자체는 방지하지 못하며 먼저 사용한 토큰만 유효합니다. QR은 실제 예약 시간과 무관한 시연용 10분 패스입니다.
정책은 제안값이고 실제 사업 운영을 위한 법적 검토를 대체하지 않습니다. 사진은 참고 이미지입니다.

## 검증

`node scripts/check.mjs` — 결제 실패, 중복 예약 롤백, 정원, 소유권, QR 1회 사용·재발급, 추가 청구, 취소·환불·시간 해제, 프런트엔드 문법 검증.
자동 검증은 통과했습니다. 브라우저 연결 호스트를 사용할 수 없어 시각 검증은 완료하지 못했습니다.
온라인 배포는 아직 연결하지 않았습니다. 로컬 서버로 전체 예약 흐름을 시연할 수 있습니다.

## 구조

- worker/index.js: 사용자 UI와 예약 API
- drizzle/: 배포 DB 마이그레이션
- scripts/local-db.mjs: 로컬 SQLite 어댑터
- scripts/preview.mjs: 로컬 실행 서버

실제 결제 연동 전까지 서비스 화면의 시연 표시를 유지하세요.
